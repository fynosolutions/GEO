# 数据库迁移

记录表结构、索引、约束及必要数据转换的有序变更。

本目录内容与职责：

- 选定数据库和迁移工具后遵循其命名与执行规范。
- 每次变更说明目的、兼容性和恢复方式。
- 迁移前评估已有数据，避免覆盖历史资料与证据。

当前包含 0000 基础资料/版本/分类明细，0001 菜单分类，0002 稳定菜系选项。npm run db:migrate 按 journal 增量执行；npm run db:generate 生成后续迁移。真实数据库、凭据和备份不放在这里。首版兼容范围及恢复限制见 docs/F1_HANDOFF.md。

美国餐馆调整使用现有分组 JSON 增加可选字段，未改变 SQL 表结构，不新增迁移或重写旧快照。新增字段读取补 unknown；旧单位和旧内容保留。写入契约升级 f1.v2，详见 docs/US_MARKET_BASELINE.md。

恢复方式：升级前停止服务并保存完整备份，保留匹配版本程序。失败迁移不继续启动；不可通过删除数据库、改写已执行 SQL 或手工复制活动 WAL 文件解决。

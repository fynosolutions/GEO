## 容量验证

独立临时实例：300 家虚构门店、30,000 条包间记录、10,200 个不同内容的小型文本附件、600 个资料版本。

| 操作 | 本机实测 |
| --- | --- |
| 列表读取，20 条摘要 | 299 ms |
| 单门店完整读取 | 4 ms |
| 完整备份 | 23,061 ms |
| 备份解压与恢复前校验 | 13,708 ms |

数据通过批量夹具构建；该测试验证数量规模、文件关联和完整包处理，不衡量真实手工连续录入耗时、大尺寸图片/PDF、低速硬盘或多年全量快照增长。日常备份耗时与文件体积和磁盘相关。

## 交付边界

仅 F1 作为实现模块；A1、B1 和 GEO 报告没有业务实现。不包括登录、自动抓取、OCR、AI 提取、自动发布、同步或跨设备访问。恢复要求当前数据库迁移版本匹配，跨版本先使用匹配程序处理。自动备份仅保留 7 份，手动备份及历史快照不自动清理；需要按实际业务数据增长安排磁盘容量。

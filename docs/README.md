# 项目文档

维护产品范围、业务数据约定、开发规则和后续功能规划。

本目录内容与职责：

- US_MARKET_BASELINE.md：当前美国餐馆、英文界面与资料、地区字段、f1.v2 变化及旧资料兼容依据。
- F1_MERCHANT_LIBRARY_PRD.md：F1 详细需求，含人工录入、共享读取、版本及交接要求。
- PRD.md：全项目范围与需求索引。
- API_CONTRACTS.md：模块边界及数据契约草案，含 F1 首批调用、状态、版本与错误规则。
- DEVELOPMENT_RULES.md：开发与协作规范。
- ROADMAP.md：当前阶段及后续功能规划。
- F1_IMPLEMENTATION.md：访谈确认的技术、数据、界面与运维基线。
- F1_HANDOFF.md：可调用接口、公开类型、字段形式、接入与协作说明。
- F1_VALIDATION.md：工程验收、实际验证及容量测试的范围和限制。

边界与约定：实现状态与规划状态分开描述；接口或业务范围变更时同步更新相关文档。

当前状态：F1 实现与验证文档已建立；其他模块仍处于需求或骨架阶段。实际通过项目见 F1_VALIDATION.md。

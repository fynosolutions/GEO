Restaurant JSON Collector

Collect Google Maps, Yelp, Tripadvisor, OpenTable, DoorDash, Uber Eats, Grubhub and Facebook into one file for your downstream system.

Platforms to collect

Only selected platforms appear in the JSON. Google Maps always resolves the restaurant identity.

Menu collection (optional)

All seven channels also search the official website, menu files/photos, Resy and Instagram. This can make additional provider calls. Menu links and dates show where administrators can view HTML menus, PDFs or images. Full details also extract dish prices. Selected-only mode limits menu collection to the checked listing platforms. Tripadvisor menu extraction is not currently supported and will be reported as unavailable.

The output file is saved to out/<restaurant-name>.json. This page is a local test interface.

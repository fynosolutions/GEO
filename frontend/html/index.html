Restaurant JSON Collector

Collect restaurant information from ten platforms. Restaurant lists produce one JSON file per restaurant.

One restaurant per line: name | full address. A JSON array of objects with name or place_id and optional address/id is also accepted. Maximum 20 restaurants. The whole list uses the platforms selected below; output is one JSON file per restaurant.

Listings · ratings and reviews
Profiles · followers and posts

This category uses followers and posts instead of rating and review count. Unavailable counts remain null. Only selected platforms appear in the JSON; Google Maps always resolves restaurant identity.

Menu collection (optional)

All seven channels also search the official website, menu files/photos, Resy and Instagram. This can make additional provider calls. Menu links and dates show where administrators can view HTML menus, PDFs or images. Full details also extract dish prices. Selected-only mode limits menu collection to the checked listing platforms. Tripadvisor menu extraction is not currently supported and will be reported as unavailable.

The output file is saved to out/<restaurant-name>.json. This page is a local test interface.

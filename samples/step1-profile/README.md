# Restaurant introduction samples

Issue #13 delivers six restaurant JSON files. Each contains records for Google Maps, Yelp and Tripadvisor. See the [reconciliation table](核对表.md) for attribute counts, screenshots and unresolved listings.

Run `npm run build` and `npm start` from the repository root, then open the local site and choose **Collect Introduction**. The [file contract](../../docs/API_CONTRACTS.md#restaurant-introductions-issue-13) describes the output.

# 商家资料页面

提供商家列表、建档、详情、分组编辑、核实、历史记录及归档恢复的页面入口。

本目录内容与职责：

- 调用 modules/merchant/ 的公开接口。
- 在页面中维护当前门店上下文和表单交互状态。

边界与约定：业务事实、字段校验和持久化由商家模块及其基础设施协作完成。

当前状态：商家列表、基础建档、11 类分组维护、明细、核实、公开范围、历史、归档、素材上传、公开导出和备份恢复已接入。workspace.tsx 组织页面状态，editors.tsx 提供表单交互。业务验证在 merchant 模块。

产品界面统一英文、桌面优先，面向美国餐馆。建档明确选择当地时区，提供 City / State / ZIP 字段；所有地区与语言校验由商家公开服务负责。旧资料和原文来源不会由页面自动翻译，详见 docs/US_MARKET_BASELINE.md。

# 文件存储适配

提供素材、证据、备份及导出文件的存取能力。

本目录内容与职责：

- 管理文件位置、读取、写入与完整性校验等技术操作。
- 业务记录通过文件标识引用文件。

边界与约定：素材和证据的业务归属由对应模块管理；此目录放存储代码，不存放真实商家文件或运行时生成的备份。默认落盘至被忽略的 .local/geobase，可通过 GEOBASE_DATA_DIR 配置。备份目录必须位于数据目录之外。

当前状态：assets.ts 保存内容寻址的不可变文件；backup.ts 流式备份、清单与完整性校验；public-export.ts 仅打包选定公开资料和素材。应用组装层负责互斥和恢复切换。

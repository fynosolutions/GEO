# 商家资料模块（F1）

维护品牌、门店、标准事实、渠道快照、素材关联、核实状态和资料历史，是商家主数据的唯一业务归属。

本目录内容与职责：

- 业务范围以 docs/F1_MERCHANT_LIBRARY_PRD.md 为准。
- public.ts：向检测、优化和报告提供稳定的读取接口。
- 提供建档、编辑、核实、归档、历史与版本化读取用例；应用组装层协调备份恢复。

边界与约定：merchant_id 对应具体门店。渠道快照不静默覆盖标准事实；对外读取应明确公开范围，内部服务档案不得默认外发。

当前状态：catalog.ts 定义字段目录；types.ts 维护公开类型；rules.ts 校验、投影与准备情况；service.ts 实现用例；public.ts 是唯一公开入口。实际接口及样例见 docs/F1_HANDOFF.md，验证见 docs/F1_VALIDATION.md。

当前公开契约 f1.v2，面向美国餐馆和英文标准资料。us-market.ts 提供地区常量、时区、工作日名称与英文字符检查；字段目录保留旧单位并新增美国字段。旧事实不会被自动翻译或换算，详见 docs/US_MARKET_BASELINE.md。
